# SideAI v0.5：连接、模式与交接

更新：2026-11-05。本指南替代 v0.3 Word 指南中的连接互斥规则。

## 先选模式

**聊天**用于文字、图片和日常问答，不调用本机工具。**Agent**用于处理项目任务；你选择执行程序、项目和权限。顶部开关会恢复该模式上次使用的会话，入口页的同一开关则切换可选 AI / Agent 卡片。

聊天模式中的 GPT 与 Agent 模式中的 Codex 是两种独立连接。Claude API 与 Claude Code 也一样。不能将旧 Agent 会话直接改成 API 会话，因为它们的执行状态、认证与历史协议不同。

窗口整体保持黑灰，仅 AI 名称显示品牌色。Enter 发送，Shift + Enter 换行；拖动顶部短横条移动窗口。

## 创建聊天连接

打开「设置 → 连接与模型 → 聊天模型连接」。

### GPT 官方账号

点击 **Continue with ChatGPT**，在官方浏览器页面确认账号、资格与授权范围，然后回到 SideAI。凭据独立保存在 macOS 钥匙串，不读取或覆盖 Codex 的登录文件；应用会校验回调、身份并按需续期。

这是独立模型调用，不是嵌入 ChatGPT 网页。计划资格、模型和额度由官方授权决定，不包含官网聊天历史、记忆或网页专属功能。本版已完成实现与本地安全协议测试，**尚未完成本机账号的首次授权及真实推理验证**；如果官方拒绝资格或授权，界面会显示错误，不会改用 Codex 或 API Key。

### API：Claude、DeepSeek、Kimi、Qwen 等

1. 点击「新建聊天连接 / 服务商预设」，选服务商。
2. 核对 Base URL、协议和账号所在区域；填连接名称与 API Key。多个账号可加「个人」「工作」等标签。
3. 点击「保存并测试」读取模型目录；不提供目录的服务可填写其官方模型 ID。目录请求成功不代表账户有足够推理余额。
4. 点击「进入聊天」，在聊天窗口下方选择模型与可用参数。

Claude 的轻量聊天目前使用 Anthropic Messages API。Claude 订阅登录通过 Agent 模式的官方 Claude Code 使用，不将 CLI 订阅 token 提取成通用 API Key。Kimi / Qwen 的区域地址必须与密钥匹配；图片和推理参数可用性取决于具体模型。

API 密钥与网页订阅通常是不同的计费入口，界面使用哪个连接，就由哪个连接承担请求。

## 避免重复连接

**不再要求 App Server 和 GPT API 二选一。** 一个是 Agent 执行入口，一个是聊天入口，可以同时保存和使用；每次发送只使用当前会话绑定的连接。

- 相同规范化地址、协议、认证方式和账号标签会被识别为重复 API 配置。更新密钥时编辑旧连接即可。
- 不同账号可以保存为不同标签；标签由用户填写，不能证明两把密钥是否属于同一个后台账号。
- 同一服务商在聊天模式一次启用一个聊天连接。切换保留其他连接和历史，不注销账号；原连接的旧聊天需重新启用它才能继续。
- 已有历史的连接不能换地址、协议、服务商或认证方式；另建连接可避免把原上下文误发到新服务。
- 官方 GPT 重新授权使用已保存连接旁的「重新授权」。如果重新新建授权产生不同的官方客户端身份，应用不能保证跨客户端识别为同一个连接。
- 请求出错不会自动换供应商或重发，避免重复计费和重复执行。

## 使用 Agent

在「设置 → 连接与模型 → Agent 连接」配置。

**Codex**：自动查找本机 CLI，也可指定路径。先点击「连接 / 重连」，再使用 ChatGPT 登录、设备码或 API Key 登录。它沿用官方 Codex 的认证与 App Server 权限机制；在这里更换账号可能影响共用该 Codex 配置的其他程序。聊天模式的独立 GPT 授权不受影响。

**Claude Code**：使用本机安装的官方 CLI。在终端完成 `claude auth login`，回 SideAI 点击「检测登录」，再进入 Claude Code。模型可选官方别名或填写 ID，实际可用性由 CLI 返回决定。

新 Claude Code 任务：只读模式允许读取、搜索；项目模式增加编辑、写入。选择项目后再发送，写入会显示确认卡片，可拒绝或仅批准本次。当前不提供 shell 命令、MCP 或后台子 Agent。旧 Claude Code 会话继续保持无工具状态；需要操作文件时创建新任务或交接。

**OpenCode / OpenClaw**：本版只有明确禁用的预留入口，尚不能执行。以后会通过各自适配器接入，保留独立执行状态，不让某一个 Agent 接管所有聊天。

## 把聊天交给 Agent

1. 在聊天上方点击「交给 Agent…」。
2. 选择 Codex 或 Claude Code，填写任务。对话背景默认空白，可以「载入最近 6 条」后删改，或自行写摘要。
3. 逐项选择图片、是否携带记忆笔记、项目和权限。不会复制隐藏推理、工具记录或旧 Agent 的权限状态。
4. 点击「创建任务草稿」。这一步只保存本地草稿；核对内容并点击发送才调用模型。如果 Codex 尚未连接，先点连接。
5. 任务页可返回「原会话」；执行完成后点「带回结果」，最后一条完整回复会追加到原会话草稿，仍不会自动发送。

关联任务保留独立历史，可以从原会话的「关联任务」找到。

## 记忆与旧会话

「设置 → 记忆笔记」保存自己维护的偏好或项目摘要，仅存本地，不自动总结、不默认跨模型共享。目前通过交接页明确勾选后使用。切换执行程序不意味着恢复另一个程序的工具状态；共享的是你确认过的文字与附件。

旧会话、草稿、模型和连接保留。升级前备份：`~/Library/Application Support/SideAI/state.pre0.5.backup.json`。状态文件中有聊天内容，但没有 API Key / OAuth token。

Codex 历史仍通过 App Server 读取；ChatGPT 网页会话可导入官方导出文件，本版不提供 ChatGPT / Claude 官网历史的自动双向同步。

## 本次验证与边界

- 自动测试覆盖连接共存、旧数据迁移、草稿交接与回传、OAuth 回调和签名身份校验、各 API 协议。
- 本机 Claude Code 真实测试验证了拒绝 Write 不修改文件，批准后才写入。
- 原生界面验证模式入口、黑灰主题、设置分区、记忆说明及未发送交接草稿。
- 独立 GPT 官方授权与云端推理仍待你完成首次登录验证；OpenCode / OpenClaw 尚未实现。预设不等于各供应商账号均已实测。
