## 自动化

- TypeScript 严格编译。
- 三种 API 协议的真实本机 HTTP SSE 流、Unicode 分片、图片块、断流、取消、重定向阻止。
- 真实子进程 NDJSON RPC、并发请求关联、服务端审批消息。
- OAuth loopback 的随机端口、state、重复参数拒绝、取消关闭监听。
- 连接去重、地址不可重定向、凭据不进入 state.json、删除后保留历史、导入去重。
- 焦点控制器：游戏 → SideAI → 游戏、重复唤出、激活失败不解锁第三方鼠标、Alt-Tab 不抢回、失效句柄不恢复。
- Windows 专属：加载 user32.dll，读取前台窗口与进程身份，验证 Win32 签名。
- Electron 源码与打包后启动检查：独立临时目录、受限 preload、主页、聊天输入焦点、审批按钮、代码块和图片预览缓存。
- 安装器检查：完整内置 npm、独立 Node.js 24，在临时目录离线安装测试包并执行 Node 脚本，无需用户预装 Node.js。
- Windows CI：安装依赖、测试、启动检查、NSIS 安装包与 ZIP 构建。
- [下载本次构建产物](https://github.com/Ikarospoipoi/SideAI/actions/runs/42183878864/artifacts/13486682487)：保留至 2026-12-06；过期后可重新运行工作流。

真实云端登录、真实 Agent 文件审批与 Windows 游戏操作不以 mock 测试冒充通过。

## 手动验收（待有 Windows 游戏环境时执行）

每个组合至少连续切换 20 次，记录「设置 → 窗口切换诊断」中的输入框确认耗时；同时观察焦点、鼠标与游戏响应。

| 组合 | 待验证项目 |
| --- | --- |
| Win11 + FPS 无边框 | 持续移动 / 瞄准时唤出；输入只进入聊天；批准后返回游戏，无卡键 |
| Win11 + MOBA 无边框 | 鼠标边缘卷屏时唤出，鼠标释放，返回后位置与输入合理 |
| Win11 + 独占全屏 | 是否最小化 / 黑屏、HDR 切换、返回延迟 |
| Win10 | 系统热键、DPAPI、窗口恢复、安装卸载 |
| 144 / 240 Hz、HDR、多显示器 | 位置、DPI、显示器拔插、帧率与切换耗时 |
| 游戏带反作弊 | 热键能否送达，后台 Raw Input 是否继续动作，是否阻止前台切换 |
| 管理员游戏 / 普通 SideAI | 不自动提权；失败提示与恢复操作 |
| 长按热键 / 键未松开 | MOD_NOREPEAT 防抖，收起等待修饰键释放 |
| Alt-Tab / 游戏退出 / 锁屏 | 不抢焦点、停止解锁鼠标、避免失效 HWND |
| 中文输入法 | Enter 确认候选不发送；Esc 优先取消候选 |
| 审批期间收起 / 切换会话 / 重连 | 请求归属准确、单次提交、断连失效、无自动批准或重放 |

「任何游戏均无缝」不是本版本已验证的承诺。若游戏在失焦后仍读取键鼠，纯桌面窗口无法保证阻止角色操作；需调整游戏后台输入或使用无边框模式。
