# SideAI 跨会话记忆（v0.10.0）

聊天和 Agent 共用本机已有的对话正文。新会话默认开启记忆；例如输入“之前 SQL 的 TRACE_ID 怎么关联”，SideAI 会搜索旧会话，将相关摘录随本轮消息交给当前连接。导入的 ChatGPT 历史无需重新导入。

## 使用

- 输入框上方点击「跨会话记忆」：按当前输入预览来源、打开原会话，或排除某条记录。
- 「继续上一个任务」：没有具体主题时，尝试引用最近一条有正文的会话，不会自动执行旧任务。
- 设置 → 跨会话记忆：全局开关、长期偏好 / 项目笔记、逐条决定会话是否允许被引用。
- 「本会话使用记忆」控制从别处读取；「允许其他会话引用这条会话」控制它是否作为来源。两者独立。
- 发送时重新检索，记录本次来源；不会把检索内容伪装成用户手打的消息。

## 读取和发送的范围

检索在本机运行，不调用云端索引或付费嵌入服务。读取已完成的用户与助手文字，跨聊天 / Agent / 服务商，也包含归档及保留的只读记录。不会索引工具输出、隐藏推理、未完成回复、图片附件或凭据目录。排除会话后，下次查询即生效。

命中的摘录会发送给**当前会话选用的服务商**，例如在 Claude 中继续 GPT 导入的 SQL 讨论。默认最多 4 条会话摘录，每条约 2,200 字符，另携带前 2,000 字的记忆笔记。不会每次上传全部聊天历史。

本版本采用本地关键词与中文词片检索，优先匹配字段名、标题及相同项目。它不是完整的语义搜索，也不保证任何模糊问法都命中；可补充主题、表名或项目名，并查看原会话确认完整内容。没有找到具体主题时，不拿无关的最近会话冒充记忆。

只能检索已有本地正文。Codex 同步后仅有标题索引、尚未打开加载正文的会话暂不参与；先打开相应历史加载正文即可。其他产品未导出 / 未同步的内容，以及官网内部个性化记忆，不会凭账号登录自动出现。Mac 与 Windows 的本地数据库仍各自独立，不是跨设备云同步。

关闭记忆不会撤回已经发送给后端的历史。要开始完全隔离的讨论，请新建会话并关闭该会话记忆；同时可禁止该会话被其他会话引用。旧任务描述与历史指令只作为背景，不改变当前项目、沙箱、工具权限或逐次审批。
