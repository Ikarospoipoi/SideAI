# 工作台（本地开发版）

本轮保留 Claude 功能和原有实现，不启动其 CLI、登录、检测或模型请求。新功能只接入非 Claude 路径；已有 Claude / Anthropic 连接与明确选择的 Claude 模型沿用原有界面和请求流程。工作区原有改动保留。

## macOS

从首页的“打开工作台”，或聊天输入框上方的“工作台”进入。

- **全文搜索**：搜索本地标题与用户／助手消息，包含导入档案和归档记录；多个关键词同时匹配，最多显示 100 处结果。点击定位到对应消息。不会联网搜索或自动同步后端历史。
- **记忆范围**：默认只参考当前目录的其他会话，可切换为指定会话或全部历史。排除标记始终优先；工具读取结束后重新检查权限。临时工作区内的聊天共享同一个目录范围。
- **固定记忆与摘要**：固定记忆在记忆开启时优先携带；固定摘要由用户填写和核对，不自动调用模型生成。全局记忆开关继续有效。
- **上下文预算**：API 与官方聊天客户端按完整用户回合保留最近上下文，默认预算约 16,000 tokens；可以调整为 4,000–64,000。原始历史和图片不会被删除。最新一轮本身超限时明确报错。Responses 历史工具循环也检查预算。估算不是服务商精确分词或费用；加密推理等不透明字段无法精确估算。Agent 的原生执行历史仍由执行器管理。
- **项目工作台**：保存项目目录、默认连接、模型、推理强度、记忆范围和常用提示词；显示最近三个相关会话。打开项目创建新草稿，不自动发送。
- **串行队列**：将草稿复制到独立任务会话，再手动开始队列。任务结束后执行下一项；失败或停止会暂停后续任务。队列暂停不打断当前任务。执行前先持久化出队，存储失败则不发送；重启后保持暂停。取消排队保留对应会话。
- **通知**：可在任务页主动开启桌面完成、失败、审批通知；系统授权通过后生效。通知仅显示状态，不显示聊天内容。不会为 Claude 产生新增通知。
- **快捷文本**：主动读取剪贴板或粘贴内容，选择翻译、解释、润色、报错分析或总结，检查后加入草稿；不会自动发送或持续监控剪贴板。
- **文件读取**：UTF-8 文本、代码和日志上限 1 MB；PDF 上限 20 MB、300 页、提取文本上限 1 MB。先在本地预览，再加入草稿。PDF 仅提取已有文本，不包含图片或 OCR；需核对表格和阅读顺序。加密或没有可提取文本的 PDF 会明确提示。
- **分支与导出**：消息右键可从该条创建分支；更多菜单支持整段分支及 Markdown／纯文本导出。Agent 分支不继承 thread／turn／权限，仅形成背景草稿；不会回滚文件。导出只含可见用户／助手正文，图片以名称标注。
- **阅读体验**：支持基础标题、列表、引用、表格、代码着色和复制；当前进程内保留会话阅读位置。不是完整 GFM／数学公式渲染器。
- **保存**：非 Claude 会话的普通延迟保存通过串行后台编码，主线程只提交当前版本；关键发送节点与退出仍同步保存，防止旧快照覆盖新内容。

## Windows

输入框旁新增“工作台”：正文搜索、记忆范围、上下文预算和固定摘要、主动读取剪贴板／UTF-8 文本文件、会话分支与 Markdown 导出。

Responses 聊天在记忆开启时支持独立的只读 `search_history` / `read_history` 工具循环。仅在完整响应结束后执行允许的工具；保留推理与工具返回的协议上下文，限制轮数、调用数和输入规模。关闭记忆后不提供这些工具。Claude 仍走原适配器。

Windows 项目配置、串行队列、PDF 文本提取尚未与 Mac 对齐；游戏焦点、原生依赖和安装包需要 Windows 真机验证。本轮完成 TypeScript 构建与离线测试，没有运行会安装官方客户端的打包流程。

## iPhone

- 会话列表可按标题搜索。
- 对支持新能力的 Mac 非 Claude 会话，可逐页加载更早历史，每页最多 30 条，每条最多 4,000 字；截断会明确显示。
- 分页沿用既有加密通道、已授权设备、握手挑战和指令去重，不执行模型或恢复 Agent。
- 当前仍不上传手机图片／文件，也不作为独立执行端。
- 按用户安排，APNs 后台推送后续接入；本轮不配置推送凭据、不宣称后台常连或后台通知。

## 验证范围

测试使用临时数据、离线界面和本机 HTTP 模拟服务，不使用真实账号或 Claude。定向覆盖搜索与跳转身份、项目排除、上下文完整回合与超限、分支执行身份清理、队列重启／失败／持久化、旧快照竞争、远程分页认证、工具循环和取消。

macOS 原生视图以离线 fixture 渲染检查；iOS 做模拟器构建。真实服务权限、通知系统弹窗、真机手机网络，以及窗口与游戏场景不由这些测试替代。

2026-11-19 本轮结果：macOS 定向回归 42 项通过，Release 构建通过；Windows TypeScript 构建与 11 项离线测试通过；iOS 模拟器构建通过。Claude 专属文件与关键分支对照本轮开工快照未发生变化。未启动真实模型请求。现有共享 HTTP 旧实现仍有 Swift 6 并发捕获警告，本轮保持原方法不变；当前 Swift 5 模式构建通过。
